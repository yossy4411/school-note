# 古墳時代の文化

## 1. 造営と葬送
- 代表: [[前方後円墳]]（例: [[仁徳陵古墳]]）  
- 副葬品: 鏡・玉・鉄製武器・埴輪（円筒・人物・家・動物）

## 2. 技術と生産
- [[渡来人]]がもたらした: [[須恵器]]・製鉄・土木・馬具
- [[鉄製農具]]普及で生産力上昇

## 3. 思想・宗教
- 祖先祭祀・自然信仰
- 外来思想の芽: [[儒教]]の礼制知識、後期に[[仏教]]伝来準備段階

## 4. 社会構造
- [[ヤマト王権]]と[[豪族]]の氏姓秩序
- [[倭王]]の中国冊封で国際的承認を得る動き

## 5. 対外交流
- 朝鮮半島諸国（[[高句麗]]・[[百済]]・[[新羅]]・[[伽耶]]）との軍事・交易
- 鉄資源・技術流入
